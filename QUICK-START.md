# QuizSmart — Quick Start

A 30-second guide to using the app.

---

## 1. Open the app

Visit the QuizSmart URL in any browser.

---

## 2. Choose your verse range

Use the four dropdowns:

- **Start chapter** and **Start verse** — where to begin
- **End chapter** and **End verse** — where to end

---

## 3. Start the quiz

Pick one:

- **▶ Start Quizzing!** — original order
- **🔀 Random Order** — shuffled

---

## 4. Use the buttons

| Button | What It Does |
|---|---|
| **🔊 Read** | Reads the question out loud |
| **⏹ Stop** | Stops the reading |
| **🔍 Show Answer** | Reveals the answer (tap again to hide) |
| **◀ Previous** | Go back one question |
| **Next ▶** | Go forward one question |
| **↺ Start Over** | Return to the setup screen |

---

## 5. Watch your progress

The bar at the bottom shows where you are — e.g., **"3 / 12"**.

---

## That's it!

Choose a range, tap **Start Quizzing!**, and go. 📘

---

**Quick fixes**

- **No sound?** Check silent mode and volume.
- **Buttons too big?** Refresh the page.
- **Data won't load?** Check your internet connection.
